Entry for the [One-Line Laugh Sprint](https://make.fun/bounty/u-daring-gecko-25-one-line-laugh-sprint-cda708b2) bounty on make.fun — one original funny line (max 200 characters) about everyday life.

## How it works

`main.py` writes a single original one-liner to `/output/entry.txt`. That line is the whole entry; an AI judge compares lines two at a time on how funny, fresh, and tightly worded they are.

## Run

```sh
python3 main.py
```
